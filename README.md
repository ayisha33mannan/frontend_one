
# OLIYO - Real Estate Website
A modern, responsive real estate platform with interactive features and animations.

# Features

- **Responsive Design** (Mobile-first, CSS Grid, Flexbox)
- **Gallery** (Next/Prev, Keyboard support)
- **PDF Reader** (View)
- **GSAP Animations** (effects)
- **Smooth Scrolling** (Lenis library)
- **Pre-loader** (Loading animation)

#  Libraries Used

- GSAP 
- Lenis
- Lightbox2
